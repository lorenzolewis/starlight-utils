:::danger[Package Deprecated]

`starlight-utils` has been deprecated.

For Multi-Sidebar migrate to [`starlight-sidebar-topics`](https://github.com/HiDeoo/starlight-sidebar-topics) by HiDeoo or [`starlight-sidebar-topics-dropdown`](https://github.com/trueberryless-org/starlight-sidebar-topics-dropdown) by trueberryless.

For Nav Links there are two options:
  - Migrate to [Starlight's Component Override](https://starlight.astro.build/guides/overriding-components/). The [`SiteTitle`](https://starlight.astro.build/reference/overrides/#sitetitle) and [`SocialIcons`](https://starlight.astro.build/reference/overrides/#socialicons) are both good starting components.
  - Migrate to [`starlight-ui-tweaks`](https://github.com/dlcastillop/starlight-ui-tweaks) by dlcastillop offers the ability for [Adding Navigation Links](https://starlight-ui-tweaks.dlcastillop.com/docs/guides/adding-navigation-links).

:::
